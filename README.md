## 🏢 About the Studio

**Kryovyn Studio** is a full-cycle development ecosystem founded by **Dmitry Voronin (@meloveh)**. We handle everything from concept and coding to server deployment and post-release support. No massive teams — just raw development and honest results.

## 🧩 Our Divisions

We operate across four specialized branches:

### 🎮 Kryovyn Games
*GTA V (FiveM) development.* Creating immersive multiplayer experiences, custom scripts, and full-scale roleplay servers.

### 🟩 Kryovyn Labs
*Minecraft development.* Experimental hub for custom shaders, complex plugins, resource packs, and bespoke server environments.

### 📱 Kryovyn Mobile
*SAMP / CRMP & Mobile Development.* Proving that great things can be built on mobile devices. Server logic and mobile-optimized mods.

### 🌐 Kryovyn Systems
*VPS, Web & Infrastructure.* The backbone of our projects. Server configuration, web development, and system administration.
